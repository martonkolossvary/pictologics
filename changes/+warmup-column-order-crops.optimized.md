The import now warms the morphology moments and the texture grey-level volume for column-order box crops. These come from a small NIfTI image or another column-order image or uint8 mask, when the ROI box fills the image or cuts only its last axis. The first run on such an input no longer compiles code (0.06 to 0.27 s for each form with an empty numba cache). A warm import takes about 0.04 s more.
