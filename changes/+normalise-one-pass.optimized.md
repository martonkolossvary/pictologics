`normalise_image` and the `normalise` step take the statistics of a whole image (no mask, no value range, only finite values, row order) with no gathered copy, and make the map (x - center) / scale in one pass (in threads from 524,288 voxels). On a 512x512x200 CT, a z-score of the whole image takes about 67 ms instead of 138 ms, and its peak memory is 400 MB instead of 850 MB. With a mask, it takes about 32 ms instead of 60 ms. The values do not change, bit for bit.
