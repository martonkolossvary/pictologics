Morphology features build their surface mesh with a new marching cubes kernel. It gives the PyMCubes 0.1.6 mesh (the same vertices and faces, in the same order), so all features are unchanged, bit for bit. Morphology takes 22-41% less time on ROIs of 36,000 voxels or more (748,000 voxels: 45 ms to 27 ms) and 6-9% less on smaller ROIs, and the default pipeline takes up to 17% less time.
