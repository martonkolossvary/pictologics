DICOM series load faster and with half the memory. The loader parsed each file twice (a header pass for the phase check, then a full read of the chosen phase); it now parses each file once, and the pixel data of the chosen phase are read when used. A rescaled series of 2^20 voxels or more, with one slice shape and pixel type, goes from its stored values through one kernel into the row-order float64 image (float64 × slope + intercept per slice, as before), and each slice is freed once copied; before, each slice became float64, the slices were stacked and the stack was copied to row order. A 512×512×200 CT series loads in 94 ms instead of 204 ms, with a peak of 528 MB instead of 1,054 MB, and the default pipeline from those files takes 38% less time and 38% less memory. Values are unchanged, bit for bit.
