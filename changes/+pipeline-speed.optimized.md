The pipeline runs faster. Its empty-ROI check reads a mask only once when both masks are one array, and it no longer runs after discretisation, which cannot change a mask. The binarize_mask step binarizes a shared mask once, so the masks stay one array and later steps also do their work once. The IVH discretisation bins only the ROI values when the configuration gives the bin limits. On a 512×512×200 CT, the default configuration takes 23% less time, and a full-resolution FBS configuration with IVH discretisation takes 33% less time and 38% less peak memory. IBSI configuration C takes 11-15% less time. Results are unchanged, bit for bit.
