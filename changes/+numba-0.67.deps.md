Pictologics now uses numba 0.67 (was 0.62) with llvmlite 0.49, and it supports Python 3.14: CI tests Python 3.12, 3.13 and 3.14. numba 0.67 gives the same IBSI values as 0.62, bit for bit, at the same speed (83 bench rows). On Python 3.14, numpy 2.3.2 or newer is needed. highdicom needs pyjpegls, which has no Python 3.14 build yet, so pip compiles it from source there (this needs a C++ compiler).
