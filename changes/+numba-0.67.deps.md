Pictologics now uses numba 0.67 (was 0.62; llvmlite 0.49) and supports Python 3.14, and CI tests Python 3.12, 3.13 and 3.14. numba 0.67 sums uint32 arrays to int64, not to uint64, so the texture kernel now adds its per-thread count tables into uint64 tables itself; all IBSI values stay the same, bit for bit. On Python 3.14 numpy 2.3.2 or newer is needed, and highdicom's pyjpegls has no Python 3.14 build yet, so pip compiles it from source there (this needs a C++ compiler).
