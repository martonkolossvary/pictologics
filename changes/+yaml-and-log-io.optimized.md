YAML configurations and the bundled templates are parsed with PyYAML's libyaml safe loader when PyYAML has it, which gives the objects of `yaml.safe_load`: `from_yaml` on the six standard configurations takes 0.38 ms instead of 2.7 ms, and `RadiomicsPipeline()` 0.4 ms instead of 3.0 ms. `save_log` writes the JSON file as it encodes it, so the whole text is never in memory (a 300-entry log: 1.5 MB peak instead of 6.1 MB); the file is the same, byte for byte.
