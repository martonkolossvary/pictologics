A pipeline run does its start-up work once instead of once per configuration: the first empty-ROI check (a scan of the whole mask), the auto-mode sentinel search, and the source mask of each source setup, which is kept until the last configuration that uses it. The package version is read once per process, and the deduplication plan of the last run is used again while the rules and the configurations stay the same. Warnings, logs and features are unchanged. Six light configurations in auto, ROI-only and full-image mode take 15-48% less time (a 512×512×200 CT: 284 ms to 181 ms).
