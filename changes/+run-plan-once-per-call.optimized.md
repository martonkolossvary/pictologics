A run makes its plan once. `run_rois()` computes the deduplication plan, the prefix keys, the configuration snapshots and the serialized step parameters once for all its ROIs. Each result Series takes the Index of its names from a cache. `run_rois()` with 200 small ROIs and intensity features takes 9.9 ms instead of 15.0 ms at 10 threads. On a 256x256x12 image it takes 9.8 ms instead of 18.3 ms. The values are the same, bit for bit.
