The pipeline now casts an in-memory float32 or integer image to float64 where it reads it. When every configuration reads only the ROI region, `run()` and `run_rois()` cut the region first and cast the cut, once per run. Some configurations read the whole image: a resample, a filter, an image-wide normalise, a binarize_mask of value 0 or source mode auto. Such a configuration casts the whole image once, as before (x1.02). The values do not change. A large column-order float32 or integer array (for example nibabel's `dataobj`) gets its cast and its row order in one pass. `run()` of a 512x512x200 float32 CT with the intensity features takes 1.0 ms instead of 34 ms (x0.031). Its peak memory is 1.8 MB instead of 400 MB.
