An in-memory float32 or integer image is now cast to float64 where the pipeline reads it. When every configuration reads only the ROI region, `run()` and `run_rois()` cut the region first and cast the cut, once per run; a configuration with a resample, a filter, an image-wide normalise, a binarize_mask of value 0 or source mode auto casts the whole image once, as before. The values do not change. A large column-order float32 or integer array (for example nibabel's `dataobj`) is cast and written in row order in one pass.
