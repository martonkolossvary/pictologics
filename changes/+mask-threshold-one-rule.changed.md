In a resample with a linear (or cubic) mask interpolation, every mask type now takes one threshold rule. It is the rule of a SEG, an RTSTRUCT or an integer array. The resample rounds the interpolated value at the threshold: value + 1 - threshold >= 1. Before, a float64 mask and a NIfTI file mask compared the value itself. The two rules differ only for a value one rounding step below the threshold. So the features of a mask with such a boundary voxel change. This is rare: 7 of the 153 IBSI 2 phase 3 scans change, by up to 14 % on one PET statistic. No IBSI verdict changes.
