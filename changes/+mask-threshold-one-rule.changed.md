In a resample with a linear (or cubic) mask interpolation, every mask type now takes one threshold rule, the rule of a SEG, an RTSTRUCT or an integer array: the interpolated value is rounded at the threshold (value + 1 - threshold >= 1). A float64 mask and a NIfTI file mask compared the value itself before. The two rules differ only for a value one rounding step below the threshold, so the features of a mask with such a boundary voxel change (rare: 7 of the 153 IBSI 2 phase 3 scans, up to 12 % on one PET statistic; no IBSI verdict changes).
