Preprocessing runs faster. Linear resampling now uses parallel kernels that give scipy's output bit for bit, also with rounding, mask thresholds, uint8 masks and source masks, which used scipy's single-core code before. Small images keep scipy's code, which is faster there. The IBSI configuration C pipeline runs about 2.3x faster. Plain linear resampling now equals scipy exactly too; before, it differed in the last bits at some edge voxels (at most 5e-13). Discretisation skips its ROI search when the bin limits are given, and filter_outliers and sentinel detection use parallel passes on large images (up to 3.8x and 6.4x faster on a 512x512x200 CT). All other outputs are unchanged, bit for bit.
