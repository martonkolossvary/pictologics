The `mask_threshold` of `resample_image` (and of the pipeline's linear or cubic mask resampling) now works for every mask type. A uint8 mask was interpolated as uint8, so its value was rounded first and every threshold acted as 0.5; a bool mask kept only the voxels whose eight neighbours were all in the ROI (in a test: 242 voxels instead of 6,945). A float64 mask still compares its interpolated value with the threshold. A uint8 or bool mask now rounds its value at the threshold, which at 0.5 is the rounding that a uint8 mask always had, so the IBSI configurations, which binarize the mask first, keep their results bit for bit. Linear mask resampling of larger images also takes 17-62% less time and a third of the memory, as the kernel now writes the thresholded mask itself.
