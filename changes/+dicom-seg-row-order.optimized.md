DICOM series, multiframe DICOM files and DICOM SEG masks of 2^20 voxels or more now load as row-order (C-contiguous) arrays, as NIfTI images did already. The DICOM series loader now stacks each slice in one piece, and the fast parallel copy to row order now also takes int16, uint16 and uint8 data. On a 512×512×200 CT series, loading takes 36% less time, and the default pipeline from the DICOM files takes 36-38% less time, with the same peak memory. A SEG mask no longer comes in column order next to a row-order image; in a test on the same CT, that mix made the pipeline 2.7-5.8 times slower. Values are unchanged, bit for bit.
