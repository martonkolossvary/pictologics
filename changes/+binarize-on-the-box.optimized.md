The `binarize_mask` step compares only the ROI box of the mask when it leaves out the value 0, keeps the box of its new mask for the later steps, and makes one comparison for one label instead of `np.isin`. On a 512x512x200 CT, a run with the step takes about 3 ms instead of 25 ms with a uint8 mask; one label of a 20-label map takes about 5 ms instead of 29 ms; `run_rois` over 300 small ROIs with an IBSI-like configuration takes a fraction of a second instead of 7.5 s. Results are unchanged, bit for bit.
