The `binarize_mask` step compares only the ROI box of the mask when it leaves out the value 0. It keeps the box of its new mask for the later steps. For one label, it makes one comparison instead of `np.isin`. On a 512x512x200 CT, a run with the step takes 3.3 ms instead of 27.4 ms with a uint8 mask. One label of a 20-label map takes 5.8 ms instead of 33.2 ms. `run_rois` over 300 small ROIs with an IBSI-like configuration takes 0.68 s instead of 8.1 s. The results are the same, bit for bit.
