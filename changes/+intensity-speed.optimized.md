Intensity features run faster. First-order statistics find their percentiles and median with one partial sort instead of two, and histogram features read them from the bin counts. IVH converts its sorted values to float64 one time, not on each search. The local intensity peak searches only the ROI box plus the reach of its sphere. Moran's I and Geary's C use FFT convolutions for large ROIs: an ROI of 117,000 voxels takes 17 ms instead of 828 ms, and IBSI configuration C runs 2.4x faster. These two values change by at most 1e-14 (relative). The FFT uses about 32 bytes per point of a grid that is twice the ROI box along each axis; above 16 GB, or above half of the memory, the pair loop runs, with a warning that gives the expected run time. All other feature values are unchanged, bit for bit.
