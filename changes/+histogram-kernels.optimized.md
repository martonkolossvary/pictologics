The histogram features of the discretised image come from two numba kernels: one counts the levels (in threads from 524,288 values), one computes the 23 features from the counts in the order of numpy's sums, so every value stays the same bit for bit. A 40-voxel ROI takes 4 us instead of 36 us, 643,000 voxels 0.21 ms instead of 1.3 ms, and 2.7 million voxels 0.41 ms instead of 5.7 ms, with no 20 MB copy. Float64 values that are whole numbers in [1, n_bins] take the same path (643,000 values: 0.23 ms instead of 6.5 ms). Their variance, skewness, kurtosis, coefficient of variation and absolute deviations now add the same terms in the order of the integer path, a relative move of at most 1e-11. A 2-D array of values raises a clear error.
