Morphology features run faster. Qhull now gets only the mesh vertices that can be convex hull vertices: along each axis, the first and the last vertex on each grid line. It finds the same hull vertices in the same order, so the maximum 3D diameter and the MVEE features are unchanged, bit for bit. The convex hull volume and area change by at most 2e-15 (relative). On large ROIs the convex hull step takes 32-65% less time, and morphology features take 11% less time on average (up to 21%).
