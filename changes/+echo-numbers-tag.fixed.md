Multi-echo series now split by their echo number. The phase detection of the DICOM loader, `get_dicom_phases` and `DicomDatabase` asked for the tag `EchoNumber`, which does not exist; the DICOM keyword is `EchoNumbers` (0018,0086). The tag was never read, so echoes split only when their slices shared positions. The multi-phase tag, the phase label ("Echo 2"), `DicomPhaseInfo.split_tag` and the database's instance metadata now use `EchoNumbers`, and a multi-valued echo number (for example `1\2`) is one group value.
