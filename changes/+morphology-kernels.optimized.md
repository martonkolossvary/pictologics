The morphology features take less time and 15-22 % less peak memory. The moments kernel has no branch, and the mesh vertex statistics use scalar accumulators. The maximum diameter of a hull below 640 vertices runs in one thread. The parallel marching cubes walks its planes in one block per thread. The morphology step copies the ROI box once, with its border. A 150^3 ROI takes 4.0 ms instead of 8.6 ms, and a 1-voxel ROI 0.06 ms instead of 0.17 ms. The MVEE stop rule of this release costs time on hulls of 200 points and more (see that entry). So a CT lesion takes 4.1 ms instead of 2.4 ms. The 20 small ROIs of a CT label map take 14.3 ms instead of 13.5 ms. The kernels of this entry give the same values, bit for bit.
