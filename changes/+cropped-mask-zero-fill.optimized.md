`load_image` with `reference_image` starts the full-size array of a cropped mask as zeros from the system when `fill_value` is 0 (the default), and writes only the box of the mask. A cropped mask that loads as float64 into a 512x512x200 grid takes 16 ms instead of 24 ms. A pipeline run with a float64 cropped mask path on an image in memory takes 18 ms instead of 26 ms. A uint8 mask loads as before. Results are unchanged, bit for bit.
