NIfTI images of 2^20 voxels or more now load as row-order (C-contiguous) arrays, through a fast parallel copy, instead of nibabel's column order. This removes a full-image copy from each discretise, resegment and resample call and speeds up full-image scans. End to end (load plus the default configuration), a 512×512×200 CT runs about 1.7x faster with about 15% lower peak memory, and large IBSI 2 validation CT cases run 4-8% faster. Feature values are unchanged, bit for bit.
