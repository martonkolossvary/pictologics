Resegmentation uses its parallel kernel from 80,000 voxels, and sentinel detection from 200,000 voxels, not from 1,048,576 (2^20) voxels. Both kernels read an image and a mask that share a column order (Fortran) without a copy, and resegmentation keeps that order in its result. On images of 262,000 to 885,000 voxels, resegmentation takes 0.17-0.33 ms instead of 0.19-2.95 ms, and sentinel detection takes 0.30-0.49 ms instead of 0.38-1.25 ms and no longer makes a full-size temporary array for each candidate value. The results are unchanged, bit for bit.
