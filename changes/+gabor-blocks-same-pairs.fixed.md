The Gabor filter gives the same values for every number of threads also with SciPy 1.18 or later. From SciPy 1.18, an FFT over a block of slices rounds each slice by the block and by its place in it. So each worker now starts its slices on an even slice, and the blocks of two slices are the same for every number of threads. The speed stays the same, and with SciPy 1.17 the values do not change.
