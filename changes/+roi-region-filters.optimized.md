The pipeline's LoG, wavelet and Laws filters filter only the region that feature extraction reads, when no later filter or resample step needs the rest of the image: the ROI box, grown by the reach of the local intensity sphere, plus the reach of the filter. The rest of the response map is 0. These filters give each voxel the same value wherever the image ends, so all features are unchanged, bit for bit. A source mask, the mean filter, the Laws energy and the FFT filters (Gabor, Simoncelli, Riesz) still filter the whole image. On images larger than their ROI, a LoG configuration takes 28-90% less time with up to half the peak memory, and a wavelet configuration takes 13-84% less time (a 512×512×200 CT: LoG 2.5 s to 0.26 s).
