The local intensity peaks run faster, with the same values bit for bit. One numba pass finds the ROI voxels and their runs along z. The sphere sums of a run read the padded row prefix sums in one piece, and a thin ROI sums voxel by voxel. The two-stage search starts at 65,536 (voxel, offset) pairs instead of 16.8 million, and small work runs without threads. A 2.3 million voxel CT ROI takes 34 ms instead of 84 ms. A 10,000 voxel ROI takes 0.30 ms instead of 1.2 ms, and a 10 voxel ROI 0.02 ms instead of 0.11 ms. Peak memory drops by up to 32 % on large ROIs. Values near the float64 limit give inf, as before.
