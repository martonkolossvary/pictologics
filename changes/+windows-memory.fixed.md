On Windows, the FFT of Moran's I and Geary's C assumed 8 GiB of memory and used at most 4 GiB, whatever the memory of the computer. Larger ROIs then took the slow loop over the voxel pairs: a thin shell of 519,640 voxels took 15 s instead of 0.6 s, and a body ROI of a 512x512x200 CT about 10 hours instead of 0.9 s. One reader now gives the memory of the computer to the whole package: `GlobalMemoryStatusEx` on Windows (its result checked), `sysconf` on macOS and Linux (each number checked), at most the memory limit of a Linux container (cgroup v2, then v1), and 8 GiB only when the system gives no valid number. The resample check uses the same reader, and its message gives GiB.
