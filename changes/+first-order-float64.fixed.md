First-order statistics now sum in float64, also for float32 values such as filter responses. Before, float32 values summed in float32, so the mean, variance, skewness, kurtosis, mean absolute deviations, coefficient of variation, energy and root mean square carried float32 rounding errors, and they depended on numpy's summation order, which numpy 2.3 changed. Now numpy 2.2 and 2.5 give the same values to within 4e-16 (relative). IBSI 2 phase 2 values move by up to 3e-7 and phase 3 values by up to 6e-4 (relative; the largest changes are coefficients of variation of filter responses with a mean close to 0). All IBSI checks pass as before, and the phase 3 team agreement is unchanged.
