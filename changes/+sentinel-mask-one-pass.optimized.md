A source mask for a sentinel value now comes from one numba pass, in parallel from 1.5 million voxels. This applies to `create_source_mask_from_sentinel` and to `source_mode="auto"` in the pipeline. The mask is the same. For a 512x512x200 CT, `create_source_mask_from_sentinel` takes 3.0 ms instead of 14.9 ms (7.9 ms instead of 14.6 ms on one thread), with half the peak memory. The source mask of a run takes 2.9 ms instead of 11.8 ms.
