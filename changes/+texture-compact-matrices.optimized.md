The pipeline, `calculate_all_texture_features` and the texture feature functions (when they calculate their own matrix) now calculate smaller texture matrices that give the same features. GLCM and GLRLM keep one table (the sum over the 13 directions) instead of 13, and GLSZM keeps only its non-zero cells. The texture set-up also reads the ROI mask only once. On the largest IBSI 2 validation CT case, the texture features run 1.5-2.2x faster with 37-56% lower peak memory. The default pipeline configuration takes 21% less time there, with 28% lower peak memory. `calculate_all_texture_matrices` returns the same matrices as before, and feature values are unchanged, bit for bit.
