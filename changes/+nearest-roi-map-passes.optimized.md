In `run_rois`, the map of the nearest ROI of a `grow_mask` step with `nearest_roi` comes from the same parallel distance passes as `grow_mask`. For 20 ROIs on a 512x512x200 CT, the map takes 21 ms instead of 390 ms. A voxel at the same distance from two ROIs can go to the other ROI than before (15 of 10.8 million map voxels in this case, none of the ring voxels). Such a voxel now goes to the same ROI on every machine, at each number of threads.
