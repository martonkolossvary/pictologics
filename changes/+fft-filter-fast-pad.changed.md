`simoncelli_wavelet`, `riesz_transform`, `riesz_simoncelli` and a 2-D `riesz_log` with the zero, nearest or mirror boundary pad each axis a little wider. Each padded axis now has a fast FFT size of the same parity. With the mirror boundary, a Riesz-Simoncelli filter of a 194x198x193 image takes 0.23 of the time at 10 threads and 0.15 at 1 thread. A Simoncelli filter of that image takes 0.64 of the time. A 256^3 or 512x512x200 image takes 0.90 to 0.91 of the time. The peak memory is 0.95 to 0.96 of the old peak. The values with a non-periodic boundary change. On a smooth test image, the change is up to 1.3e-1 of the response range. On an IBSI 2 phase 3 CT scan, it is up to 5.5e-2. Against a reference with a 64-voxel pad, the new values are closer in most cases. The periodic boundary (the default) does not change. In the "Simoncelli Boundary" table of the IBSI 2 phase 3 page, 56.0 % of the mirror values are within 1 % of the range (before: 56.3 %).
