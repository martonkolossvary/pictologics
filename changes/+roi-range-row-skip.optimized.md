The ROI minimum and maximum skip the image rows without ROI voxels. One vectorised test of each mask row finds these rows. This range gives the default bounds of FBN and FBS discretisation, the FBS bin count of the pipeline and the GLCM grey-level span. On a 512x512x200 CT with a small lesion, the range takes 0.36 ms instead of 1.7 ms (1.0 ms instead of 13.7 ms on one thread), and `discretise_image` with FBN 32 takes 47 ms instead of 60 ms on one thread. Results are unchanged, bit for bit.
