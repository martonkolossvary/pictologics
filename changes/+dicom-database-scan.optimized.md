`DicomDatabase.from_folders` starts worker processes only for large scans: at most one worker per 1,000 DICOM files, and the DICOM check of each file (132 bytes) runs in the calling process. Each worker imports Pictologics before it reads a file, and the scan started a pool of `cpu_count - 1` workers twice, whatever the number of files. With the default settings, a 200-file series now takes 0.06 s instead of 3.4 s. The database is unchanged.
