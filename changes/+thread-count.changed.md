The FFT filters (Simoncelli and Riesz), the FFT sums of Moran's I and Geary's C, and the threads of the rotation-invariant wavelet and Laws filters, the Gabor filter and `save_slices` now use numba's thread count (`NUMBA_NUM_THREADS` or `numba.set_num_threads()`), not all cores. One setting now limits all threads of a process, for example when several processes run at the same time. By default all cores run, as before; the Laws and Gabor filters used Python's default of the cores plus 4 threads. The values are the same, bit for bit, and the speed is the same (199 bench rows, two runs).
