`resample_image()` and the resample step now copy a column-order image into row order with the tiled parallel copy of the loaders. An example is an array from nibabel's `get_fdata()`. A bool source mask takes the same copy. A 1 mm resample of a 512x512x200 column-order CT takes 27 ms instead of 252 ms. `run()` of `standard_fbn_32` on such an image and mask takes 32 ms instead of 376 ms. Row-order arrays and the values do not change.
