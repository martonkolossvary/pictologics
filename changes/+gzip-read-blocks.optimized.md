`load_image` decompresses a `.nii.gz` file that `save_image` wrote on the threads of the package, with the block index of its gzip header (from 4 MB of compressed data). The kernel converts each block to float64 as it comes, so the stored array is not made. A 512x512x200 float64 CT loads in 0.18 s instead of 0.86 s, and a float32 CT in 0.12 s instead of 0.44 s. Other gzip files load as before.
