The wavelet filter runs its 1-D passes in numba kernels that keep the arithmetic of scipy. Each line sums in double, the last tap first, with fused multiply-adds. The kernels read each plane once in memory order and skip the zero taps of the a trous kernels of level 2 and above. The values are the same bits. At 10 threads the IBSI 2 wavelet configurations run 1.7-3.2 times faster. Phase 3 configuration 7 on a CT scan takes 69 ms instead of 222 ms, and configuration 6 54 ms instead of 119 ms. A 256^3 image takes 7.6 ms instead of 26 ms. At 1 thread the filter is 2 times faster. The tree of shared passes of the rotation-invariant wavelets writes into one buffer for each depth instead of a new array for each chain. A 256^3 rotation-invariant LHL filter takes 108 ms instead of 335 ms, and a 512x512x200 CT 318 ms instead of 431 ms. A NaN or inf voxel now spreads over the non-zero taps of a level-2 kernel only.
