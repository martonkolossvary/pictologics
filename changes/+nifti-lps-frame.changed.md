NIfTI images now give their origin and direction in the LPS+ frame, as DICOM images and SimpleITK do. The loader changes the sign of the X and Y rows of the RAS+ affine. Code that reads `Image.origin` or `Image.direction` of a NIfTI image as RAS+ must change. An in-memory `Image` is in LPS+ too. The warning about mixed NIfTI and DICOM frames is gone, because the frames no longer mix.
