The minimum volume enclosing ellipsoid (MVEE) of the morphology features now stops on the Mahalanobis gap, with away steps (Wolfe-Atwood), at eps = 3e-3. The old stop rule left the ellipsoid 0.3 to 0.5 % too small, so `volume_density_mvee_SWZ1` and `area_density_mvee_BRI8` were 0.2 to 0.5 % too large. Against a tight fit (eps 1e-8) on 34 masks, the new values are within 0.17 % (SWZ1) and 1.0 % (BRI8). IBSI gives no reference for these two features, so no IBSI result changes. The MVEE of a CT lesion hull of 690 points takes about 2.5 ms instead of 0.4 ms; `run_rois()` of 20 small ROIs with the morphology features takes about 2 % more time than with the old stop rule.
