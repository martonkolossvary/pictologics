The intensity-volume histogram (IVH) counts whole-number float values as it counts integers, from 4,096 values on instead of 131,072. Below 1,048,576 values, the count runs on one core. The IVH of 643,000 whole float64 values takes 0.6 ms instead of 4.0 ms. The IVH of 300,000 rounded CT values takes 0.3 ms instead of 4.3 ms. Its peak memory is half. The search for the intensity at a volume fraction no longer builds an array over the whole value range. Take a bin width of 1 over values from -4e6 to 4e6. The search then takes 6 ms and 12 MB instead of 40 ms and 230 MB. The values are the same, bit for bit.
