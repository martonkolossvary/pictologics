The Simoncelli and Riesz transfer tables of 3-D images are now built by parallel numba kernels. A filter call on a new image shape is faster. On a 512x512x200 grid with 10 threads, the Simoncelli table of level 1 takes 16.5 ms instead of 196 ms, and the Riesz table 7.7 ms instead of 92 ms. A Simoncelli filter of level 1 on a new 512x512x200 shape takes 111 ms instead of 295 ms. A Riesz-Simoncelli filter there takes 133 ms instead of 422 ms. The values are the same, bit for bit.
