The sentinel search now counts the 6 default values with one faster numba pass, and a run no longer counts the found value a second time. This applies to `detect_sentinel_value` and to `source_mode="auto"` without `sentinel_value`. The result is the same. For a 512x512x200 CT with an ROI, the search takes 7.7 ms instead of 12.0 ms. The search step of a run takes 7.8 ms instead of 24.8 ms, with no temporary array of the image size. With the one-pass source mask, an AUTO run with intensity features on that CT takes 11.6 ms instead of 38.2 ms.
