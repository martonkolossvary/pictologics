In the pipeline, an axial Gabor filter (not averaged over planes) filters only the slices of the region that feature extraction reads, when no later filter or resample step needs the rest of the image. Each slice is filtered on its own over its whole plane, so the features are unchanged, bit for bit. A Gabor configuration takes 21-45% less time on images with slices outside the ROI region (a 512×512×200 CT: 196 ms to 128 ms, 423 MB to 307 MB).
