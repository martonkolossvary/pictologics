A mask or an image that `load_image` turns to the voxel order of `reference_image` now copies on a tiled parallel kernel when numpy's copy reads across the cache. The values are the same bits. A 512x512x200 mask with reversed axes loads in 21 ms instead of 140 ms (uint8, as the pipeline loads it); the turn of a float64 image takes 17 ms instead of 247 ms. With X and Y swapped, the turn of a float64 image takes 17 ms instead of 71 ms. On one thread, only reversed axes of large arrays change: 81 ms instead of 255 ms.
